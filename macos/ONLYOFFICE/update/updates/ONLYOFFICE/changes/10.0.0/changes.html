ONLYOFFICE 10.0.0 - {{DATE}}

New features

All Editors

  • Updated the start page: moved the buttons to the left sidebar and redesigned the cloud service and template panels
  • Removed local document templates (only online templates remain)
  • Removed the AI plugin from the default package; it is now installed as an add-on
  • Reduced the window border thickness and added a window shadow (Linux)

Document Editor

  • Added the horizontal line settings window
  • Implemented clipping of text by lines in a paragraph with exact line spacing
  • Added support for the keepNext parameter for tables, as well as for paragraphs and tables inside block content controls
  • Improved support for graphic equations and other inline objects in right-to-left (RTL) text
  • Implemented a table row option that prevents a row from breaking across pages
  • Added items for continuing a list or restarting numbering to the Paste Special menu
  • Implemented the ability to go to another user's cursor and follow it during co-editing

Spreadsheet Editor

  • Added range highlighting in the formula bar
  • Added saving to the XLS format
  • Sped up some operations by storing styles and data separately
  • Implemented creating charts from non-adjacent data
  • Added an option to enable and disable AutoComplete for cell values
  • Added tooltips for constants in function arguments (the AGGREGATE function)
  • Added an animated selection border after copying or cutting
  • Implemented support for sheet background when opening and saving files
  • Improved performance of array formulas that reference entire columns or rows (ROW, COLUMN, SEQUENCE, SUM, SUMPRODUCT, etc.): calculations are faster and use less memory
  • Extended the capabilities for working with hidden rows and columns, including unhiding hidden edge rows and columns via the context menu

Presentation Editor

  • Extended print settings: added modes for printing notes, handouts, and outline, as well as printing hidden slides, slide background and frame, comments, slide numbers on handouts, and fitting to the page size
  • Added view modes: Outline, Notes, Handout Master, and Notes Master
  • Added the Reading View mode
  • Added the Animated and Video buttons to the File menu for exporting a presentation with a choice of slide range, resolution, slide duration, and format
  • Set a separate default duration for each transition type

Forms

  • Added the ability to save a signature in signature fields and reuse it from the list of saved signatures
  • Added an option to enable and disable spell checking when filling out a specific form

PDF Editor

  • Implemented removal of annotations in the Redact area
  • Added the ability to remove metadata from a document using the Redact feature
  • Added the annotation settings panel
  • Added the ability to insert a signature into a document via the Comment tab
  • The Comments panel now displays all annotations indicating their type
  • Added the ability to edit PDF form actions via Advanced Settings in the form settings panel
  • Implemented creating and filling out forms by roles, as well as collecting data from filled-out forms
  • Added recognition of tables with visible borders in the Edit Text mode
  • Added the signature field to the Forms tab in the Edit PDF mode
  • Added field visibility options to the right form settings panel

Convert

  • Added support for the OFD format: files can be opened for viewing and converted to other formats in the same way as XPS

AI

  • Added the ability to install AI Tools (beta) with support for ONLYOFFICE Document Builder functionality, PowerShell and Bash command execution, as well as calculations in macros and in the agent itself
